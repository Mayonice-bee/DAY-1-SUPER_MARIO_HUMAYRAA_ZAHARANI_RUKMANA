# DAY-1-SUPER_MARIO_HUMAYRAA_ZAHARANI_RUKMANA
1. Deskripsi Repository

Repository ini berisi dokumentasi kegiatan Day 1 Proyek Workshop, yang terdiri dari sesi Pengenalan Akademik TIK, pemaparan Studi Independen, PBL, dan Magang, serta workshop Building with AI, Managing Change with GitHub. Isinya mencakup rangkuman materi, pengetahuan baru yang saya pelajari, dan pendapat pribadi saya tentang kegiatan tersebut.

2. Tujuan Repository

- Mendokumentasikan materi workshop Day 1 secara rapi dan terstruktur.
- Menjadi catatan belajar pribadi tentang prompt engineering, Git, dan GitHub.
- Menjadi bukti penerapan alur dasar version control (init, add, commit, push).
- Memenuhi ketentuan tugas Day 1 Proyek Workshop.

3. Rangkuman Kegiatan Workshop

Pengenalan Akademik TIK (Bpk. Hatta)
Membahas visi JTIK menjadi jurusan bertaraf internasional yang berdaya saing dan berdampak, dengan misi pendidikan vokasi, riset dan inovasi, serta tata kelola digital. JTIK juga bermitra dengan banyak pihak seperti Pemkot Depok, Huawei, dan Agate.

Studi Independen, PBL, dan Magang (Bu Euis dan Bu Maria)
Lewat Kurikulum Merdeka, kegiatan di luar kampus seperti magang dan studi independen bisa dikonversi menjadi SKS. MBKM adalah payung kebijakannya, dan MSIB adalah program magang serta studi independen bersertifikat. Tips suksesnya: kenali minat, konsultasi dengan dosen, siapkan CV dan portofolio, serta dokumentasikan kegiatan.

Building with AI, Managing Change with GitHub (Nugi Farhan)
Prompt AI yang baik terdiri dari Role, Task, Context, dan Format sehingga hasilnya lebih tepat. Git adalah alat version control lokal, sedangkan GitHub adalah platform online untuk menyimpan repository dan berkolaborasi. Alur dasarnya: `git init`, `git add`, `git commit`, lalu `git push`. Praktiknya membuat aplikasi Student Task Planner dengan bantuan AI dan mengunggahnya ke GitHub.

4. Poin Penting dan Pengetahuan Baru

- Prompt yang spesifik menghasilkan output AI yang lebih baik, tetapi hasilnya tetap harus diuji sendiri.
- Git dan GitHub berbeda: Git bekerja secara lokal, GitHub secara online.
- Perubahan harus di-`add` dan di-`commit` dulu sebelum di-`push`.
- Magang dan studi independen bisa dikonversi menjadi SKS, jadi perlu direncanakan sejak dini.
- CV, portofolio, dan dokumentasi kegiatan penting sebagai bekal karier.

5. Pendapat Pribadi

Menurut saya, Day 1 Proyek Workshop sangat bermanfaat. Sesi pengenalan akademik memberi gambaran arah jurusan dan peluang selama kuliah, sedangkan sesi workshop memberi keterampilan praktis memakai AI dan Git/GitHub. Bagian paling menarik adalah perbandingan prompt tanpa konteks dengan prompt terstruktur, dan bagian paling menantang adalah setup Git dan SSH key. Saran saya, sediakan panduan setup tertulis dan beri waktu praktik lebih banyak.
